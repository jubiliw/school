# تشغيل خادم معامل

يتطلب التشغيل المحلي Node.js 24. من جذر التطبيق استخدم `npm run build` ثم `npm run dev`. يفتح الخادم واجهة التطبيق المبني على `127.0.0.1:4173`. تُنشأ قاعدة SQLite في `.local/maamel.sqlite`. يقبل الخادم `PORT` و`MAAMEL_DEV_DB`، بما فيها القيمة `:memory:` للاختبارات المؤقتة. اختبارات الخادم تعمل بأمر `node --test backend/*.test.mjs`.

## البيئات والحسابات

شغّل كل بيئة بقاعدة مستقلة. يحتاج نشر Worker إلى ربط D1 باسم `DB` وتطبيق `backend/schema.sql` قبل استقبال المستخدمين. المعلم والطالب يسجلان باسم دخول واسم عرض وكلمة مرور. اختبر الرحلة العامة ببيانات اصطناعية. كل معلم جديد يحصل على تجربة ٣٠ يومًا وحد قدره ستة فصول. يحدد مشغل النظام الباقات والصلاحيات من لوحة الإدارة.

تُمنح صفة الإدارة خارج التسجيل العام. يجب التحقق من هوية المشغل وموافقة صاحب الخدمة قبل ترقية حساب سبق إنشاؤه. لتجهيز مشغل اختبارات فقط، استخدم اتصال قاعدة بيانات بيئة الاختبار وأمرًا بمعاملات مربوطة:

```sql
UPDATE users SET role='admin' WHERE id=? AND username=?;
DELETE FROM sessions WHERE userId=?;
```

تعرض لوحة الإدارة المدارس والمعلمين والمستخدمين وحدود الاشتراكات والاستخدام وسجل التدقيق. ترتبط المدارس بمعلمين، ويملك كل معلم فصوله. تعيين معلمين في نفس المدرسة يشاركهم حد الفصول في باقة المدرسة. تستمر قراءة الصفوف القديمة عند انتهاء الباقة، ويحتاج إنشاء فصل إضافي إلى رصيد فصول نشط. لا توجد عملية تحصيل مالي.

## حفظ الأعمال ومراجعتها

ملفات الطالب الافتراضية جزء من لقطة حالة الواجب. حد حجم جسم الطلب ٦٤٠ كيلوبايت. يُرسل رقم النسخة مع الحفظ أو التسليم. يعود الخادم برمز 409 عند سبق حفظ نسخة أحدث. يبقى تسليم كل محاولة محفوظًا مع الحالة والدرجة والتعليق وتاريخ التسليم. يستطيع المعلم إعادة فتح عمل مُسلّم، حتى بعد موعد التسليم. يتطلب حذف حساب المستخدم تأكيد كلمة المرور، ويحذف أعماله حسب علاقات قاعدة البيانات. حذف حساب معلم يحذف أيضًا فصوله وواجباتها والتسليمات المرتبطة.

## التنظيف والاحتفاظ

يضبط مشغل المدرسة عدد أيام الاحتفاظ بالأعمال المسلّمة. القيمة الفارغة تعني بقاء الأعمال إلى أن يُحذف حسابها أو يضبط المشغل مدة. مع تفعيل مُشغّل الجدولة في بيئة الاستضافة، تحذف الدالة `scheduled` دفعة تصل إلى ألف عمل مسلّم تجاوز مدة المدرسة، وتشمل محاولاته. تنظف الجلسات وقيود المحاولات المنتهية وسجلات التدقيق الأقدم من ٩٠ يومًا. سجّل اختبارات استعادة واحتفاظ لكل بيئة فعلية. اختيار مدة ومعالجة بيانات حقيقية يحتاجان مراجعة مالك الخدمة والجهة التعليمية.

## نسخة احتياطية محلية قابلة للاستعادة

```sh
node scripts/database.mjs backup .local/maamel.sqlite .local/backup-01.sqlite
node scripts/database.mjs restore .local/backup-01.sqlite .local/recovered-01.sqlite
```

يأخذ الأمر لقطة SQLite متسقة ويفحص سلامتها ومفاتيحها الخارجية. يتطلب مسار وجهة جديدًا ويقصر أذونات الملف عليه. الاستعادة تلغي الجلسات القديمة وتبقي الأصل محفوظًا. النسخ تحتوي على بيانات مستخدمين وتقتضي تشفير مخزن النسخ وتقييد الوصول إليه. يُختبر مسار النسخ والاستعادة المحلي في `backend/operations.test.mjs`. يحتاج D1 المُدار إلى نسخ واستعادة من مزود البيئة وإجراء اختبار استعادة على قاعدة أخرى قبل تشغيله ببيانات حقيقية.
