# معامل
إعداد المعلم وسام عبدالله جبيلي

مساحة تدريب للرابع الابتدائي. يحتوي هذا المجلد على التطبيق المستقل وقاعدة متطلبات الصف واختبارات النماذج والحسابات. تستمر مداخل سطح المكتب وWord وAccess السابقة في جذر المستودع. في نسخة سطح المكتب الأصلية كانت النجوم تُحتسب من أحداث الواجهة، وفي Word كان زر المراجعة يعرض تنبيهًا. يفحص التطبيق الجديد حالة العمل عند التسليم.

## التشغيل والاختبار
يتطلب Node.js 24 أو أحدث. من هذا المجلد شغّل npm install ثم npm run build، وبعدها npm run dev. يخزن خادم التطوير الأعمال في SQLite محليًا. نفّذ npm test للتحقق من النماذج وواجهات الحسابات. المجلد curriculum يضم مصفوفة المنهج وترحيل قاعدة الجرد وفحص صفحات المصدر.
 
## الاستخدام
من «دخول الحساب» أنشئ حساب معلم تجريبيًا ثم فصلًا وواجبًا. انضم بالرمز من حساب طالب في متصفح مستقل. احفظ النشاط وسلّمه وراجع الدرجة من «نتائج الطلاب». التدريب الحر منفصل عن الواجبات التي تتطلب حسابًا.
 
## التشغيل السحابي
يخدم Worker واجهة المستخدم وواجهات API تحت نطاق واحد وتُربط به قاعدة D1 باسم DB. يجب تطبيق ترحيلات drizzle قبل التشغيل. ملفات الدراسة الأصلية وقواعد حسابات التطوير مستبعدة. التشغيل التجاري واعتماد الرابع يتطلبان إغلاق فجوات المنهج واختبار الأجهزة والتحقق من سياسات التشغيل والخصوصية والاسترجاع.
