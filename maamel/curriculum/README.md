# مرجع الرابع الابتدائي

إعداد المعلم وسام عبدالله جبيلي

يربط الملف grade4.sqlite سجل صفحات نسخة الكتاب الأصلية بالمصفوفة المصححة ذات 27 درسًا. ثماني وحدات منهجية في جزأين، وثمانية مشروعات، وثماني مجموعات تقويم ختامي. للقسم الإضافي عن الذكاء الاصطناعي سجل مستقل خارج عداد الدروس والوحدات الثماني. المعرّفات G4-01 إلى G4-27 مأخوذة من جرد الدروس المصحح. أُعيد إثبات درس تنسيق الفقرة ص74–82 الذي سقط من جدول أقدم. صححت تسميتا درسي استخدام اللبنات وإدخال البيانات بالرجوع إلى الأصل.

## استعراض الشواهد

افتح view-source.html واختر ملف الرابع الأصلي من جهازك. تحسب الصفحة SHA-256 محليًا وتعرض ملاحظة كل صفحة مع الأصل في قارئ PDF المدمج. عرض رقم الصفحة وتحديد موضعها يعتمدان على قارئ المتصفح. يحتوي التوزيع على الملاحظات الأصلية فقط. ترقيم المصفوفة هو ترتيب صفحات PDF ابتداءً من 1، وأرقام الصفحات المطبوعة الظاهرة في المتن توافقه. صفحات الغلاف غير المرقمة يحددها ترتيب PDF فقط.

| الملف | الاستخدام |
|---|---|
| lessons.json | بيانات الجزء والوحدة والدرس ونطاق الصفحات |

## إعادة البناء

من هذا المجلد، شغّل الأوامر التالية باستخدام Python 3 ومكتباته القياسية. استخدم مسار إخراج جديدًا عند نسخ الجرد.

```sh
python migrate.py grade4.sqlite
python migrate.py /tmp/maamel-with-grade4.sqlite --inventory /path/to/maamel_curriculum.sqlite
python test_migration.py
```

يرث أمر الترحيل سجل الكتب التسعة بكامل صفحاته البالغ عددها 3317. الجداول الجديدة تبدأ بالبادئة ma_، وترتبط بالمفاتيح الأصلية في books وpages. للتحديث اللاحق شغّل migrate.py على نسخة الإخراج دون خيار inventory. يحافظ التحديث على حالات التطوير القائمة. قاعدة الجرد الكاملة تضم نصوص المقررات. استخدمها داخليًا.

## حدود الاعتماد

تمت معاينة صور الصفحات الـ317 وتسجيل موضوع كل صفحة وشواهد الخطوات أو الأنشطة الظاهرة عليها. كانت المعاينة على مستوى لوحة الصفحة، ولم يُسجّل كل سهم أو عنصر بصري أو حوار صغير على حدة. سجل المراجع يشمل أمثلة الدرس والتدريبات والأسئلة والمشروعات، وقد تجتمع عدة أسئلة أو مهام في ملاحظة واحدة. لا تمثل معايير القبول الـ45 تفصيلًا لكل بند في الكتاب. اجتاز تسعة معايير اختبار التسليم والتصحيح على خادم التطبيق المحلي. تحمل المعايير الـ36 الأخرى حالة «تم التحقق من المصدر». لم يُختبر ربطها المباشر بمهام الخادم في سجل الأدلة هذا.

تحتاج مواضع الأدوات الدقيقة والأصول التابعة للتمارين إلى تحقق مستقل وتوثيق حقوق الاستخدام أو صنع بديل أصلي. لم تُراجع فروق الإصدارات الحالية من البرامج، ولم يُعتمد الصف الرابع أو يُفتح الصف الخامس.

## أدلة اختبارات التسليم

يصل run-acceptance.mjs إلى مدخل الخادم المعتاد backend/index.mjs بقاعدة SQLite جديدة وحسابات مصطنعة لكل نشاط. ينشئ المعلم فصلًا وواجبًا، ويسلّم الطالب عملًا به خطأ ذو أثر، ويعيد المعلم فتح الواجب، ويحفظ الطالب العمل المصحح ثم يستعيده ويسلّمه. يجري التحقق من سجل المحاولتين ودرجة لوحة المعلم. لا يتضمن ذلك تشغيل واجهة المتصفح أو تجربة خدمة سحابية منشورة.

تتضمن server-evidence.json نتائج فعلية لاختيار الأجهزة ص19، ونقل الصور ص32، ومثلث القلم ص155، ومشروع الملعب ص157، وخلايا الرسالة ص224، وتكلفة الرحلة ص238، وسرعة الروبوت ص291، والدائرة ص298، ومسار المربع ص300. تربط ma_task_evidence كل تشغيل بالمعرف البرمجي للمهمة وبصمة الشيفرة ودرجة العمل الناقص ودرجة التصحيح. يضم سجل الخادم 18 تسليمًا ضمن تسعة اختبارات. المعرفات المستقرة وتفاصيل كل حالة موجودة في trace-cases.mjs. يمكن إعادة الاختبارات باستخدام Node 24 واستيراد نتائجها كأدلة إضافية.

```sh
node run-acceptance.mjs /path/to/app server-evidence-new.json
python import_evidence.py grade4.sqlite server-evidence-new.json
```

لاستعراض المعايير التي ما زال ربطها بحاجة إلى إثبات:

```sql
SELECT s.section_id, s.page, s.title, t.criterion
FROM ma_skill s JOIN ma_requirement r ON s.id=r.skill_id
JOIN ma_activity a ON r.id=a.requirement_id
JOIN ma_acceptance t ON a.id=t.activity_id
WHERE NOT EXISTS (SELECT 1 FROM ma_run x WHERE x.acceptance_id=t.id AND x.passed=1)
ORDER BY s.page;
```
